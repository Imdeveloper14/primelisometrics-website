11. Calculation Methodology & Governing Equations

Naval architecture governing equations in execution order.

/* 1. GEOMETRIC & DYNAMIC SIMILARITY */ λ = LS / LM Fn = V / √(g · L) VS = VM · √λ /* 2. TOWING-TANK MODEL RESISTANCE DECOMPOSITION */ qM = ½ · ρM · VM² · SM CTM = RTM / qM CFM = 0.075 / (log₁₀ReM − 2)² (ITTC-1957) CR = CTM − (1 + k) · CFM (Residuary derivation) /* 3. FULL-SCALE SHIP RESISTANCE RECONSTRUCTION */ ReS = VS · LS / νS CFS = 0.075 / (log₁₀ReS − 2)² CTS = (1 + k)·CFS + CR + ΔCF + CA + CAA qS = ½ · ρS · VS² · SS RTS = qS · CTS /* 4. PROPULSION & POWERING */ PE = RTS · VS (Effective power) ηH = (1 − t) / (1 − w) ηD = ηO · ηR · ηH (Quasi-propulsive eff.) PD = PE / ηD PB = (PD / ηS) · (1 + SeaMargin) (Installed brake power)

12. Engineering Principles & Transparency

Clarifications on William Froude's extrapolation framework.

The Froude Separation Principle (1868)
Total resistance is split into frictional drag (dependent on Reynolds number Re) and residual drag (dependent on Froude number Fn). Because both Reynolds and Froude numbers cannot be matched simultaneously in water towing tanks, testing is performed at identical Fn, and friction is calculated analytically.
Residuary Resistance vs Theoretical Wave Resistance
Important distinction: This calculator extracts residuary resistance CR directly from physical towing-tank force gauge measurements (CR = CTM − (1+k)CFM). It does not predict wave drag from theoretical potential-flow source distributions (Michell/Rankine panel methods); rather, it carries measured empirical tank drag across to the full-scale vessel via Froude similarity.
Form Factor (1 + k)
The 3D viscous form factor accounts for accelerated potential flow and 3D boundary layer thickening around a streamlined hull compared to a 2D flat plate of equal wetted surface.
Turbulence Stimulation Requirement
Model basin test runs below Re = 10⁶ risk laminar boundary layer detachment and premature separation. Basins fit sand-strips or trip studs near the bow to ensure fully turbulent flow.
